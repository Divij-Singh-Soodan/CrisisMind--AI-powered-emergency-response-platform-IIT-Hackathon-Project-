# CrisisMind--AI-powered-emergency-response-platform-IIT-Hackathon-Project-



CrisisMind in Layman’s Terms

CrisisMind is an AI-powered emergency assistant that helps people make better decisions during emergencies. When someone describes a crisis—such as a fire, road accident, medical emergency, or natural disaster—the AI quickly understands the situation, tells them how serious it is, provides immediate first-aid or safety instructions, and guides them to the nearest emergency services.

Instead of searching the internet or panicking, users get clear, step-by-step guidance within seconds.

⸻

Example

A user types:

“My father suddenly has severe chest pain and is sweating.”

CrisisMind will:

* Recognize it as a potentially critical medical emergency.
* Advise the user to call emergency services immediately.
* Provide first-aid instructions while waiting for help.
* Show nearby hospitals.
* Present the information in a clear, easy-to-follow format.

⸻

Components of the Project

1. User Interface (Frontend)

This is what the user interacts with.

It includes:

* Landing page
* Chat interface
* Emergency response screen
* Severity indicator
* Nearby emergency services
* Emergency action buttons

Its job is to collect user input and display AI-generated guidance.

⸻

2. Backend Server

This is the brain that connects everything.

Its responsibilities are:

* Receive the user’s emergency description.
* Process the request.
* Communicate with Gemini AI.
* Return structured results to the frontend.
* Handle errors and API communication.

⸻

3. AI Engine (Gemini)

This is responsible for understanding the emergency.

It:

* Interprets the user’s message.
* Classifies the severity.
* Generates immediate safety or first-aid guidance.
* Summarizes the situation in a structured format.

⸻

4. Emergency Services Module

This module helps users locate relevant nearby services, such as:

* Hospitals
* Police stations
* Fire stations

It makes the AI’s advice actionable by directing users to available resources.

⸻

5. Response Display

Instead of showing a long paragraph, CrisisMind organizes the information into:

* Severity level (Low, Medium, High, Critical)
* Immediate actions
* Things to avoid
* Nearby emergency services
* Quick action buttons

This makes it easier to understand information during stressful situations.

⸻

One-Line Summary

CrisisMind is an AI-powered emergency response assistant that analyzes a user’s emergency, assesses its severity, provides immediate guidance, and helps connect them with appropriate emergency services through a simple and intuitive interface.
